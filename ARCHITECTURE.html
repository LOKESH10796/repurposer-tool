Repurposer Tool — Architecture

Next.js 16 App Router • React 19 • TypeScript Strict • Tailwind CSS 4

📥

Data Sources

  • User-pasted text
  • CSV upload (Papaparse)
  • YouTube transcript API
  • URL fetch (future)
API

Next.js Route Handlers

  • /api/repurpose — Core orchestration
  • /api/analyze — AI sentiment & tone
  • /api/generate — Format generation
  • /api/export — CSV/TXT export
🧠

AI Services

  • Google Generative AI (Gemini)
  • HuggingFace Transformers
  • Zod input validation
  • @types/canvas-confetti feedback
🖥️

Frontend (App Router)

  • app/page.tsx — Landing
  • app/api/repurpose/route.ts — Orchestration
  • hooks/ — Custom React hooks
  • lib/ — Shared utilities (CSV, AI client)
🔐

Authentication

Clerk Next.js SDK v7

  • Sign-in / Sign-up
  • Session management
  • Protected routes
🔄

Data Flow

User input → Validation (Zod) → AI Analysis → Content Generation → Format Output (CSV, social, blog, etc.) → Export / Display
